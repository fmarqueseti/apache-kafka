# Apache Kafka — Temperature Sensor Demo 🚀

🇧🇷 Bem-vindo(a) ao meu projeto de demonstração do **Apache Kafka**! Aqui você encontrará uma _stack_ completa montada com **Docker Compose** e **Node.js**: um producer IoT simulado publica leituras de temperatura a cada segundo, um consumer lê as mensagens de volta e uma interface web permite acompanhar todo o pipeline em tempo real.

**Para a versão em português, clique [aqui](README_BR.md).**

🇺🇸 Welcome to my **Apache Kafka** demo project! Here you'll find a complete stack built with **Docker Compose** and **Node.js**: a simulated IoT producer publishes temperature readings every second, a consumer reads the messages back, and a web UI lets you monitor the whole pipeline in real time.
